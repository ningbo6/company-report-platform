# 素材来源

- 学校官网：https://www.hd-u.com/ ，已核对页面标题“邯郸职业技术学院”。
- 官网页头原图：https://www.hd-u.com/images/logo.png ，获取于 2026-10-15，568×113，RGBA。
- `school-emblem-preview.png`：从上述页头左侧裁取的 113×113 校徽，仅用于预览与二维码测试，不作为高清原件交付。未使用 AI 重绘或虚构高清细节。
- 当前没有取得官方独立高清校徽。正式导出需要补充至少 512×512 的原始清晰素材，配置 LOGO_PATH 和 LOGO_READY=true。
- 标签字体：Noto Sans CJK SC Regular，来自 https://github.com/notofonts/noto-cjk ，字体原文件 https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf 。按 SIL Open Font License 使用，授权见 `FONT-LICENSE.txt`。

SVG 导出中，二维码模块为矢量路径，学校校徽为嵌入 PNG；不会将位图描述为矢量校徽。

透明格式验证：当前校徽为 RGBA PNG，四角 alpha=0。二维码生成保留原始透明通道，不加矩形白底；导出包附带 `assets/school-logo-transparent.png`，输出目录同时保留独立 PNG。原始小尺寸素材仍仅用于预览，不因透明格式处理而成为高清原件。
